Visual Manifesto — vox-humana

editorial for humans

alpha 0.1

vox-humana is not an AI interface.
It is an editorial machine for human work.

It exists for people who listen, translate, revise, direct, compare, cut, approve and deliver voice. It is a tool for the craft around speech: the text before the voice, the pause before the line, the human decision before the render.

The interface must feel like a working surface.
A page.
A console.
A proof sheet.
A studio desk.
An archive drawer.
A red light waiting for a take.

Technology is present, but never theatrical.
The machine is visible, but not dominant.
The human remains the scale.

⸻

1. Human first

The visual system begins with the word: human.

Large, direct, black typography.
No decorative softness.
No synthetic friendliness.
No startup optimism.

The typography should feel printed, not sprayed with effects. It should have the authority of a book cover, a studio label, a film leader, a manual, a record sleeve, a piece of equipment with its function written plainly on the front.

vox-humana should not look like it is trying to impress the user.
It should look like it is ready to work with them.

⸻

2. The editorial machine

The interface is a machine, but an editorial one.

Its parts are panels, cards, strips, labels, markers, columns, tracks, references and states. It should carry the feeling of analog equipment and printed matter: physical compartments, visible hierarchy, mechanical clarity.

The product should evoke:

* audio consoles;
* tape machines;
* modular panels;
* printed labels;
* film editing tables;
* archive cards;
* book margins;
* proof pages;
* technical manuals;
* constructivist layouts;
* studio hardware;
* Ableton Live 9;
* paper systems made for repeated use.

Every module should answer a practical question:

What exists?
What is approved?
What is active?
What is missing?
What happens next?

⸻

3. Paper, books and the page

The base surface is not “white UI.”
It is paper.

Off-white, warm grey, ivory, aged stock, matte surfaces, subtle contrast. The screen should carry some memory of paper: margin, weight, quiet, readability, editorial discipline.

Text is not secondary in vox-humana.
Text is the source material.

The product handles translation, localization, rhythm, timing and voice. Therefore the visual system must respect reading. It must make versions, approvals, notes and commands feel like editorial objects rather than software noise.

Use the page as a model:

* strong titles;
* compact labels;
* clear columns;
* quiet margins;
* visible annotations;
* restrained emphasis;
* dense information with room to breathe.

A good vox-humana screen should feel like a page that can operate a machine.

⸻

4. The red signal

Red is not decoration.
Red is signal.

It is the recording light, the editorial mark, the warning, the selected take, the active state, the human decision point. It should be used with restraint and force.

Red can mean:

* active;
* recording;
* selected;
* needs attention;
* blocked;
* approved with consequence;
* ready for action.

The red circle, the red lamp, the red mark on paper: these are central references.

The interface should not glow everywhere.
One red point should be enough.

⸻

5. Black geometry

Black gives the system weight.

It should appear as typography, dividers, control surfaces, buttons, rails and hard contrast. Black is ink, hardware, shadow, silence, equipment.

Use black for structure.
Use red for decision.
Use off-white for work.
Use earth and organic tones for temperature.

The geometry may be strict: rectangles, panels, vertical strips, index marks, modular blocks. But it should never become sterile. The human softness comes from proportion, rhythm, paper tone, language and restraint.

⸻

6. Nature as atmosphere, not ornament

Nature should not appear as decorative leaves, eco-icons or soft illustrations.

It should enter as atmosphere:

* dark green almost black;
* moss;
* bark;
* wet stone;
* soil;
* shadow;
* filtered light;
* warm paper;
* organic silence.

The reference is not “nature branding.”
It is a studio near the forest.
A technical room with books, wood, cables, microphones, paper, humidity, listening and time.

Nature reminds the product that voice is physical.
Breath, mouth, body, pause, intention.

⸻

7. Interaction must feel physical

A professional tool cannot leave the operator wondering whether anything happened.

Every interactive element must respond.

Buttons should feel pressed.
Copy actions should confirm.
Refresh actions should show that they are working.
Blocked states should explain why.
Processing states should be visible.
Disabled controls should never look broken.

Required states:

* hover;
* active;
* focus;
* disabled;
* loading;
* copied;
* success;
* warning;
* error;
* blocked.

The feedback should be firm, not playful.
Like a switch, a lamp, a meter, a stamped mark.

⸻

8. Complexity with dignity

vox-humana works with a complex pipeline. The interface should not pretend otherwise.

It should not hide complexity behind fake simplicity.
It should organize complexity so that a professional can act.

Each workflow view should make clear:

1. where the project is;
2. what artifacts exist;
3. what is approved;
4. what is missing;
5. which voice reference is active;
6. which JSON will be used;
7. which render mode is selected;
8. which command is recommended;
9. what output is expected;
10. what comes next.

Complexity is acceptable.
Confusion is not.

⸻

9. Anti-slop principles

vox-humana rejects the generic aesthetics of AI products.

Avoid:

* purple neon;
* glassmorphism;
* floating SaaS cards;
* decorative gradients;
* magical language;
* generic assistant metaphors;
* emoji decoration;
* excessive shadows;
* cute empty states;
* over-rounded components;
* fake simplicity;
* interfaces that look generated.

The product should not look “smart.”
It should make the operator feel situated, capable and in control.

⸻

10. Tone of voice

The interface should speak like a competent post-production team.

Direct.
Calm.
Precise.
Human.
Never promotional.

Prefer:

* Project created.
* Transcription approved.
* Voice refs found.
* Manual reference active.
* TTS segments detected.
* Next step: Assembly / Sync.
* Command copied.
* Render blocked: missing tts_safe_final.json.

Avoid:

* Unlock the power of AI.
* Create magic.
* Supercharge your content.
* One-click creativity.
* Your AI copilot.

vox-humana is not selling a dream.
It is helping someone finish the work.

⸻

11. Brand expression

Name:

vox-humana

Signature:

editorial for humans

Version:

alpha 0.1

The name should appear with restraint.
The product does not need a loud logo system. The identity comes from the interface itself: typography, paper, panels, red signal, black structure, human language.

The brand is not futuristic.
It is contemporary, editorial and alive.
⸻

12. Summary

vox-humana is a human-scale editorial machine for AI dubbing.

It combines:

* the discipline of books;
* the precision of audio tools;
* the clarity of technical manuals;
* the atmosphere of paper and archive;
* the modularity of studio hardware;
* the signal language of recording equipment;
* the organic presence of voice and nature;
* the judgment of human professionals.

The machine assists.
The human listens.
The human decides.

The interface should never erase that.
